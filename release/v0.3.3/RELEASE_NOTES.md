# 屙了么 PoopedYet v0.3.3 正式版发布说明

> **记录每一次舒畅时刻的温润手帐 · 纯本地私密存储 · 温暖治愈系日历打卡**

---

### 🌟 核心更新与亮点

#### 1. 桌面小组件与前台实时灵动胶囊全链路升级
- **深度夜间深色模式适配**：新增 Android 原生层 `values-night-v31` 与 `values-night/colors.xml` 专属暗色资源定义，在暗色壁纸与系统暗黑模式下呈现自然通透的高品质深色质感；
- **锁屏实时灵动通知图标升级**：新增矢量通知专用图标 `ic_live_notification.xml`，适配系统状态栏极简纯色规范；
- **防社死体面暗号模式**：支持一键隐藏敏感词，将排便术语替换为体面日程术语；
- **全链路原子化快照推流**：记录编辑、重新打开、人员划转、补录与数据还原后，自动完成双向实时推流同步。

#### 2. 自研物理阻尼弹簧抽屉与多级触觉震动反馈 (HapticFeedback)
- **系统级硬件触觉引擎**：
  - 水平侧滑位移**越过触发阈值瞬间**触发清晰物理触感（`mediumImpact`）；
  - 手指往回拉回退阈值时触发轻微触感（`selectionClick`）；
  - 侧滑结束与删除操作带专属触感反馈；
- **物理阻尼手感**：配合自研弹簧复位曲线（`Curves.easeOutCubic`）与无缝圆角贴合底板，实现如真实纸张抽屉般的顶级操作体验。

#### 3. 渲染性能调优与内存防泄漏全面闭环
- **列表项 RepaintBoundary 重绘隔离**：在主页打卡列表中为每项卡片精准隔离重绘边界，彻底阻断呼吸脉冲动画的高频重绘波及链，大幅降低 GPU 光栅化能耗；
- **控制器生命周期闭环**：对补录底表、自定义便便感受、单行编辑对话框中所有临时 `TextEditingController` 全面加入 `try...finally { controller.dispose(); }`，根治内存泄漏隐患；
- **时间合法性二次防御**：补录记录提交前增加 `_end != null && _end!.isBefore(_start)` 校验，彻底阻断非法负时长记录落库。

#### 4. 数据备份恢复与 WebDAV 同步交互重构
- 重构数据备份与导出恢复页面（`DataBackupPage`），提供更清晰的备份记录时间戳与导入导出模式说明；
- 优化 WebDAV 私有云同步状态机（`WebDavSyncPage`），更友好的连接测试反馈与增量合并容错体验。
