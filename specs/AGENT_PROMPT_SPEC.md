### 2. 启动页 (Splash Screen) 与图标规范
- **应用图标 (`assets/icons/app_icon.png`)**：1024×1024 满铺直角 PNG，供 `flutter_launcher_icons` 及 Android `mipmap` 直接使用。
- **原生启动屏 (`android/app/src/main/res/values/styles.xml`)**：适配 Android 12+ SplashScreen API，背景 `#FAF8F5`，中心图标使用 `drawable/splash_icon.png`（由 `assets/images/splash_logo_safezone.png` 缩放到 288×288 生成）。
- **应用内启动页 (`lib/ui/splash/splash_screen.dart`)**：
  - 居中展示 `assets/images/splash_logo_safezone.png` + `屙了么` + `PoopedYet`。
  - 中下部展示正式品牌标语：`“日理万机，屙了有记”` 与 `Every Poop, Accounted For.`。
  - 底部随机展示一条幽默健康提示语（如：`💡 提示：蹲坑不要超过十分钟，谨防腿麻和痔疮...` 或 `💡 Poop Happens. Log It. 每一坨都值得被记录...`）。
  - **重要约束**：启动页底部**不显示版本号**，保持极简干净。
- **日常宣传口号 (`Poop Happens. Log It.`) 的应用落位**：
  - 日历选中日期无记录时的空状态面板 (Empty State)。
  - 分享打卡海报/月度肠胃报告底栏角标。
  - Android 桌面快捷打卡小组件 (AppWidget) 副标。

## 三、 核心业务功能模块拆解

### 模块 1：屙屎人管理 (Pooper Profile Management)
1. **属性字段**：`id` (UUID)、`name` (昵称)、`avatar` (预设 Emoji 头像或本地相册裁剪图)、`remark` (备注)、`isDefault` (是否为默认人)。
2. **多用户与默认逻辑**：
   - 首次启动应用时，数据库自动初始化一个默认屙屎人（名称：“本尊”，头像：“👦”，`isDefault = true`）。
   - 支持添加多个屙屎人（例如伴侣、家人、宠物或小号），并可随时将任意一人设为默认。
   - App 顶部导航栏右侧常驻显示当前选中的屙屎人头像与名称，点击可快速切换或进入管理弹窗。

### 模块 2：拉屎记录与实时备注 (Poop Tracking & Real-time Notes)
1. **一键开屙 / 新增记录**：
   - 点击主界面底部“一键开屙”或“新增记录”时，**默认自动选中默认屙屎人**，**开启时间 (`startTime`) 默认自动填入当前系统时间**。
2. **结束时间非必填 (`endTime` Nullable)**：
   - 记录创建后可处于“进行中 (`endTime == null`)”状态，卡片顶部显示实时流逝时长（由 `now - startTime` 动态计算），并提供【填入结束时间】按钮；点击后将当前时间写入 `endTime`。
   - 用户也可以手动编辑开启时间、结束时间，或者将结束时间留空（仅作为单时间点打卡）。
3. **多条实时备注与预设标签**：
   - 每次拉屎记录下可挂载多条备注 (`List<RecordNote>`)。
   - 每条备注自动记录添加时刻的实时时间戳 (`timestamp`)，展示为时间轴子项（如 `14:22:05 · [拉肚子] 肚子咕噜叫`）。
   - **预设备注标签库 (`PresetTag`)**：系统内置常用标签（`拉肚子`、`顺畅`、`黄金香蕉`、`干硬费劲`、`腿麻了`、`带薪拉屎`），支持用户在设置或打点面板中**手动增添自定义常用备注**。

### 模块 3：历史补记与上下分栏日历看板 (Schedule Calendar View)
1. **上半部分：日历组件 (`TableCalendar`)**：
   - 支持右上角一键切换 **月视图 (`CalendarFormat.month`)** 与 **周视图 (`CalendarFormat.week`)**。
   - **日期假期与调休显示**：集成 `lunar` 库读取中国法定节假日安排，在对应日期格右上角渲染微标：`休`（珊瑚红底白字）或 `班`（石板灰底白字），普通日期底部辅以农历初一/十五或节气简写。
   - **对应屙屎人当天数量徽标**：统计当天各屙屎人的拉屎次数，在日期格下方渲染微缩头像 + 次数（如 `👦2` 或 `👦2 👧1`）。
2. **下半部分：选中日期的拉屎日程列表**：
   - 展示选中日期当天的所有拉屎记录卡片（含屙屎人头像、起止时间、耗时、实时备注时间线）。
   - 列表顶部右侧提供 **【+ 补记/新增】** 按钮：允许用户为过去某一天补录历史拉屎记录与多条备注。
