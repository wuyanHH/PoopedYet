## 1. 方案定位与设计哲学

桌面小组件并非主 App 的简单缩放，而是**针对桌面碎片化场景的“即刻触达入口”与“生活节律观察窗”**。

在融合方案中，我们确立三大核心支柱：
1. **纸质手帐美学 (Paper Journal Aesthetic)**：延续暖米纸色、焦糖印章与得意黑斜体数字，让小组件如同贴在手机桌面上的精美撕历与手帐便签。
2. **极速零阻力记录 (Zero-Friction Action)**：将“一键开屙”与“结束计时”提到最顶层，消灭多级菜单跳转与等待。
3. **体面隐私防护 (Dignity & Privacy)**：内置一键“体面暗号模式”，彻底规避公共场合、办公室被旁人窥屏的社死风险。

| `--brand-ink` | `#9A5219` | 焦糖色链接文字、已打卡实心印章数字 |

| `--work` | `#4A7C8C` | 日历格右上角调休上班（班）角标 |

### 2.2 字体与排版

- **数字、计时、日期标题**：**得意黑 (Smiley Sans)**，启用 `tabular-nums`，确保等宽防抖动；
- **正文与备注**：**Noto Sans SC** (400 普通常规 / 600 次粗 / 800 加粗)；
- **阴影**：统一采用暖调投影 `rgba(94, 66, 42, 0.08)`，严禁中性灰投影；
- **图标**：统一使用 **Lucide** 细线图标（2px stroke，圆头描边），**严禁使用任何彩色系统 Emoji**。

### 3.1 小号小组件 (Small · 2×2) ——「撕历打卡戳 + 即刻开屙」

- **适用场景**：主屏一隅，核心抓取“当日排便状态”与“最快速开屙/掐表”。
- **标准逻辑尺寸**：170pt × 170pt（iOS）/ 2×2 网格（Android）。
- **内边距 (Padding)**：四周 14pt，卡片内圆角 22pt。

#### 布局线框与信息结构

### 3.2 中号小组件 (Medium · 4×2) ——「即时行动舱 + 7天迷你手帐周历」★ 核心主打

- **适用场景**：手机主屏黄金中段。左侧满足当下的操作与状态，右侧提供 7 天规律感与家庭多人视角。
- **标准逻辑尺寸**：360pt × 170pt（iOS）/ 4×2 网格（Android）。
- **双区分割**：左侧行动舱占 38% 宽度，右侧周历占 62% 宽度，中间由 1px `--line` 分隔。

#### 布局线框与信息结构

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 屙了么 · 便签手帐                       2026年3月 · 第14周 (连续顺畅5天★)│
│ ────────────────────────────────────────────────────────────────────── │
│ ┌─ [左侧 38%：即时状态与操作] ─┐  ┌─ [右侧 62%：迷你 7 天周视图] ────┐ │
│ │  🐶 我 · 今日已记 1 次       │  │  周一 周二 周三 周四 周五 周六 周日 │ │
│ │  上次: 08:30 (顺畅)          │  │   24   25   26   27   28   29   30  │ │
│ │  距今 4 小时                │  │  🐶1  🐶2  🐶1   休  🐶1  🐶2 (今天)│ │
│ │                             │  │  🐱1       🐱1            🐱1 [🐶1] │ │
│ │ ┌─────────────────────────┐ │  │ ─────────────────────────────────── │ │
│ │ │ ＋ 现在开屙             │ │  │ 今日动态：咪咪尚未排便               │ │
│ │ └─────────────────────────┘ │  │ 点击右侧任一格查看当天详情 →        │ │
│ └─────────────────────────────┘  └────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────────┘
```

#### 元素精确规格：
1. **周历 7 列网格**：
   - 每列宽约 26pt，列间距 3pt；
   - 顶部星期标签（`周一`~`周日`，10px `ink-3`）；
   - 日期数字（得意黑 12px）；
   - 右上角休/班角标（7px，红/蓝实底白字）；
   - 格内头像徽标：12×12pt 圆形头像背景色 + 7px Lucide 图标 + 8px 频次角标；
   - **今天高亮**：焦糖 1.5px 内描边，底色使用 `--surface-2` (#FFFCF6)。
2. **左侧动态变化**：
   - 处于开屙状态时，左侧区域自动切换为大秒表计时（得意黑 26px）+ `[✓ 完事]` 按钮，不破坏右侧日历网格的稳定性。

### 3.4 锁屏小组件 (Lock Screen) & 实时活动 (Live Activity / 灵动岛)

#### 1. 锁屏小组件 (Lock Screen)
- **圆形 (Circular, 36×36pt)**：
  - 外圈为环形达成度（当日完成 1 次即为满环，未打卡为虚线环）；
  - 中心展示当前默认成员的 Lucide 矢量图标。
- **矩形 (Rectangular, 160×45pt)**：
  - 第一行：`[lucide-dog] 我 · 距上次 4小时`；
  - 第二行：`今日已记 1 次 · 点击现在开屙 ＋`。
- **单行文本 (Inline)**：
  - 显示在锁屏时间上方：`屙了么: 距离上次 4h · 今日已打卡`。

#### 2. 灵动岛与实时活动 (Live Activity & Dynamic Island)
在任何场景（App 内或小组件）点击“开屙”后，系统触发 Live Activity：
- **灵动岛紧凑态 (Compact)**：
  - 岛左侧：抹茶绿呼吸脉冲圆点（持续平缓脉冲）；
  - 岛右侧：得意黑实时滚动计时器（如 `09:12`）。
- **灵动岛长按展开态 (Expanded) / 锁屏通知实时活动卡片**：
  - 顶部：成员姓名（如“🐶 我 正在如厕中”）；
  - 中间：大号跳动计时秒表（字号 32px 得意黑）；
  - 右下角：常驻 **`[✓ 完事]` 快捷动作按钮**。用户上完厕所熄屏前在锁屏点一下即可直接完成保存，无需解锁进入 App。

## 4. 全局「体面隐私/暗号模式」规范 (Incognito Mode)

为保护白领、学生等用户在办公室或公共交通上免受尴尬，提供可自由切换的暗号映射规则：

| 界面位置 | 常规手帐模式 | 体面隐蔽模式 (暗号模式) | 隐喻说明 |
|---|---|---|---|
| **小组件标题** | 屙了么 · 便签手帐 | PoopedYet · 日常轻体 | 转换为英式生活手帐 |
| **小号按钮** | ＋ 现在开屙 | ＋ 减负放空 | 职场解压隐喻 |
| **小号完成按钮** | ✓ 完成并记录 | ✓ 减负达成 | 阳光积极 |
| **进行中提示** | 正在屙... | 正在深度放空中... | 似带薪摸鱼与沉思 |
| **今日汇总** | 今日 1 次 · 顺畅 | 今日放空 1 次 · 轻松 | 完全规避排泄敏感词 |
| **上次时间** | 上次: 08:30 (4h前) | 上次放空: 08:30 (4h前) | 体面表达 |
| **未打卡提示** | 咪咪尚未排便 | 咪咪待减负 | 养宠温和用语 |

## 5. 交互行为与 Deep Link 路由契约

由于系统安全机制，小组件与主应用间通过规范的 URL Scheme 进行协同：

| 触发热区 | Deep Link 路由 | 行为逻辑 |
|---|---|---|
| **点击「＋现在开屙」** | `poopedyet://action/start?pooperId={id}` | 后台写入一条新进行中记录并刷新小组件；若系统不支持直接后台动作则秒开 App 弹起开屙弹层 |
| **点击「✓完成/完事」** | `poopedyet://action/finish?recordId={id}` | 写入结束时间 `endedAt=now()`，落库并重置小组件为常态 |
| **点击周历某一格** | `poopedyet://calendar?date={YYYY-MM-DD}` | 打开主 App 日历并自动聚焦定位到该选中日期 |
| **点击多成员头像/卡片** | `poopedyet://pooper/{id}` | 打开主 App 并切换当前默认成员 |
| **点击大号「补录便签」** | `poopedyet://action/create_manual` | 打开 App 并弹出补录底表 |

## 6. 数据架构与跨进程同步方案

由于 Flutter 本身运行在单独的宿主进程，而原生小组件（iOS Widget Extension / Android Glance AppWidget）运行在独立的系统宿主进程中，必须建立高效、低开销的跨进程共享通道。

```text
┌─────────────────────────────────────────────────────────────┐
│ Flutter 主应用 (Drift SQLite / Riverpod)                    │
│                                                             │
│ 每次发生：开屙、结束、补录、修改人、改设置                     │
│ 触发 -> WidgetSnapshotService.updateSnapshot()              │
└──────────────────────────────┬──────────────────────────────┘
                               │ 写入轻量 JSON / 共享偏好
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 共享数据桥接层                                               │
│ • iOS: App Group 共享容器 (UserDefaults / JSON 文件)         │
│ • Android: 跨进程 SharedPreferences / File Provider         │
└──────────────────────────────┬──────────────────────────────┘
                               │ 通知小组件系统重载
                               ▼
┌──────────────────────────────┴──────────────────────────────┐
│ 原生小组件渲染引擎                                          │
│ • iOS: WidgetKit (SwiftUI) + ActivityKit (Live Activity)    │
│ • Android: Jetpack Glance (Kotlin 声明式 Compose 风格组件)  │
└─────────────────────────────────────────────────────────────┘
```

## 7. 落地实施路线图 (Roadmap)

- **阶段一 (核心轻量版)**：
  - 完成 Flutter 侧 `WidgetSnapshotService` 序列化与跨进程存储桥接；
  - 交付 **小号 (2×2)** 与 **中号 (4×2)** 组件的 iOS (SwiftUI) 与 Android (Glance) 原生模板渲染；
  - 调通 `poopedyet://action/start` 与 `finish` 快捷动作通道。
- **阶段二 (高级体验版)**：
  - 接入 **iOS Live Activity / 灵动岛** 实时如厕计时；
  - 实现锁屏小组件 (圆形/矩形/单行)；
  - 全局加入「体面暗号模式」开关配置支持。
- **阶段三 (完整看板版)**：
  - 交付 **大号 (4×4)** 全家手帐看板与 14 天节律热力图；
  - 完善边缘情况处理（超时未关智能兜底、跨零点归属）。
